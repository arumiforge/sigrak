# Agents in this repository

All agent rules live in [`CLAUDE.md`](CLAUDE.md). Read it first; it applies to every AI agent and session working in this repository.

**Codex** (visual assets): read [`ai/CODEX.md`](ai/CODEX.md) and follow it, then [`ai/style-guide.md`](ai/style-guide.md)
and the brief. Your scope is `ai/generated/` plus the `status:` lines of the briefs you delivered and the queue in
`ai/README.md`. Never change application code, docs or anything else; never copy client logos or licensed template
sources (such as Hugeicons Pro files) into an asset.

Rules for every agent:

- Commit as `Arumi Studios <arumiforge@gmail.com>` (`git config user.name "Arumi Studios"`,
  `git config user.email "arumiforge@gmail.com"`, `git config core.hooksPath .githooks`).
- Conventional Commits in English. **No AI attribution of any kind**: no `Co-authored-by`, no `Claude-Session`, no
  "Generated by/with …" lines, links or tool footers in commits, pull request titles, bodies or comments. The
  commit-msg hook and CI reject them.
- Open a pull request into `main` and never merge it; Arumi Studios merges.
- The repository is private and proprietary (`LICENSE`); never publish its contents.
- Docs, briefs and commits in English; anything users see in Indonesian; URL slugs in Indonesian.
