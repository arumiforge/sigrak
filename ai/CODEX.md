# Instructions for Codex: make the visual assets of SIGRAK

You make the visual assets for **SIGRAK** (a web app for Indonesian SD/MI teachers, principals and supervisors:
lesson plans, question banks, worksheets, school administration), built by Arumi Studios. Claude (the developer agent
of this repository) writes the briefs, reviews your pull request and wires the assets into the app. You do not touch
application code.

## 1. Scope (strict)

- Add or change files **only inside `ai/generated/`**, plus the `status:` line of the briefs you delivered and the
  Status column of the queue in `ai/README.md`.
- Never change application code, `docs/`, other briefs or anything outside `ai/`. Never copy client logos, school
  logos or licensed sources (Hugeicons Pro files, template kits) into an asset.
- Work on a new branch `art/codex-<YYYYMMDD>-<batch>` from the latest `main`; **one pull request into `main`** per
  batch. **Never merge it.**

## 2. Git identity and commit rules

```bash
git config user.name "Arumi Studios"
git config user.email "arumiforge@gmail.com"
git config core.hooksPath .githooks
```

- Conventional Commits in English, e.g. `feat(ai): add empty-state paintings (002)`.
- **No AI attribution anywhere**: no `Co-authored-by`, no "Generated by/with …", no tool links or footers in commits,
  PR title, body or comments. The commit-msg hook and CI reject them.

## 3. Read first

1. `ai/style-guide.md` — identity, respect rules, cast, palette, painting and SVG rules (they win over a brief).
2. The briefs of your batch in `ai/prompts/` (queue in `ai/README.md`).

## 4. Deliver

- Masters in `ai/generated/` and ready-to-install files in `ai/generated/install/`, mirroring the app's asset folders
  (`img/<area>/…` for images, `css/…` for styles), with exactly the file names the brief gives.
- WebP for paintings within the brief's size budget, on real transparency; SVG without scripts, event handlers or
  external references; CSS animations that stop under `prefers-reduced-motion`.
- No text, letters, numbers or Arabic-like marks inside images unless the brief asks for it.
- SVG and CSS briefs: a preview page `ai/generated/demo/index.html` showing every asset in light and dark at 360 and
  1280 px.
- Run `python3 ai/tools/check_assets.py <IDs>` and fix every error before opening the PR.
- In the PR body: the batch, one line per asset (ID, file, size), anything you could not do and why.
