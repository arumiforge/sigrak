# Documentation

| Folder | Purpose | Language |
|---|---|---|
| `agent/` | Context, progress, decisions, workflow, and task files for agents and sessions | English |
| `agent/tasks/` | One file per task (`<ID>-<slug>.md`) | English |
| `agent/archive/` | Finished phases moved out of `PROGRESS.md` | English |
| `drafts/` | Documents in progress | English |
| `final/` | Approved documents | English |
| `pdf/` | Generated PDFs of final documents, for developers to read | Indonesian |
| `handbook/` | The owner's personal handbook (one HTML page): decisions, stack, server, plan | Indonesian |
| `server/` | Server guides: SSH key from scratch, first SSH access, Bitvise, Cloudflare Access, setup flow, Compose layout, terminal safety | Indonesian (commands and output English) |
| `templates/` | Templates for tasks and documents | English |
| `sources/` | Owner-supplied material and official documents, kept as received except personal data removed (input only, D-409) | As received |
| `data/` | Prepared data for later import (e.g. curriculum CP extracted from official documents). JSON keys English, content as in the source | English keys; source language |
