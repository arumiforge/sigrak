# Data pre-check: regulation extracts (RS-15, D-447)

- **Files checked:** the 18 JSON files in `docs/data/regulations/` (the folder holds 18 JSON files plus `README.md`).
- **Sources:** the matching PDFs in `docs/sources/` (see `docs/sources/README.md`); `deep-learning-slides.json` against `Paparan_Pembelajaran_Mendalam_Kemendikdasmen.pdf`.
- **Date:** 2026-11-27. Read-only check: no data file was changed.

Method:

1. SHA-256 of every source PDF compared with `source.sha256`. Metadata (number, title, issuer, set, promulgated and in-force dates, BN numbers, revokes/amends, signatories) read from the body and signature pages. Image-stamped dates were read from page renders (`pdftoppm`). E-signatures were re-checked with `pdfsig`.
2. Every quoted string (3,362 strings, all keys except `summary`, `note`, keys and codes) was compared with the PDF text (`pdftotext -layout` and plain mode) on the cited pages ±1. A Python `-I` script normalised case, whitespace, hyphenation, line breaks, page headers and footers, and split quotes on `…`. Every miss was then read by eye. OCR noise in the scanned 126/P and 127/P decrees and the watermark fragments in 17/2026 were confirmed as noise.
3. Article numbering was checked by finding the enclosing `Pasal` heading for each quoted article (1/2026, 9/2026, 12/2024, 13/2025). All JP table cells were checked (13/2025 Tabel 1–5 and 16–20, kokurikuler Tabel 6 and 8). The CP index Fase A–C start pages were checked for all 17 SD subjects.
4. Image-only pages and figures were rendered and read: 13/2025 p. 9 signature, 1/2026 p. 9, 9/2026 p. 5, 12/2024 p. 14, 127/P p. 26, slides pp. 42, 43, 50, 51, 58, assessment guide pp. 35, 112, 114, KSP guide pp. 23, 96, 97, KKA paper p. 91.
5. Summaries were spot-checked for claims that drive app behaviour. These are the claims bolded in the regulations README, such as rombel limits, graduation grades, AN participants, Pokja deadline, BI transition, KKA grades and JP, and template required/optional fields.
