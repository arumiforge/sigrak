# Data pre-check: master taxonomy and regulation registry

Task RS-15 (D-447). Read-only pre-check; no data file was changed.

- **Files checked:** `docs/data/taxonomy/facet-a-policy.json` … `facet-h-administration.json` (8 facets, 326 nodes), `docs/data/taxonomy/regulations.json` (38 regulations, 28 relations), cross-checked with `docs/data/regulations/*.json` and `docs/data/curriculum/subjects.json`.

Main ones: Permendikdasmen 13/2025 (pp. 2–21), Permendikbudristek 12/2024 (pp. 5, 7, 9, 13–14), Permendikdasmen 10/2025 (pp. 3–4), Panduan Pembelajaran dan Asesmen 2025 (pp. 39, 44–48, 54–55, 64–66), Panduan Kokurikuler 2025 (pp. 8, 10–11, 28–33), Kepmendikdasmen 126/P/2025 (pp. 3, 5, 12, 14, 17, 28), 127/P/2025 (pp. 3, 6), 56/2026 (pp. 1, 3, 53), Paparan Pembelajaran Mendalam (pp. 26–29), KMA 512/2026 (pp. 2, 9–10, 23–24, page images), KMA 1503/2025 (p. 28, page image), Kepka BKPDM 020/2026 (pp. 1, 3, page images), Perdirjen GTK 7607/2023 (full text), Permendikdasmen 1/2026, 6/2026, 9/2026, 26/2025, Permendikbudristek 21/2022.
- **Date:** 2026-11-27.
- **Method:** `pdftotext -layout` into the scratchpad; scanned or garbled pages read as page images (`pdftoppm`). Then each node with a `regulation` reference was read against the cited pasal or page.
