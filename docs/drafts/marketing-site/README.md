## How the drafts were written

- **Claims:** only what v1 contains per `docs/final/product-concept.md`. No numbers except prices, durations and counts fixed by decisions (4 wizard steps, 18 supervision instruments, 30 TKA items, 14 working days, 5 schools for Sigrak Binaan, 1-month AI usage log, 30-day public chatbot log, 7/30-day backups, RPO 5 min / RTO 1 h). No testimonials, user counts or school names. Speed promises from the product concept's "three proofs" (for example "under a minute") are targets, not measured results, so the copy does not use them.
- **Trial and sign-up (D-459):** every trial button says "Coba gratis" and goes to `https://app.sigrak.com/daftar`. The trial length is a setting (extendable when it ends, changeable per user or per school), so the copy names no number of days. A teacher signs up alone; when the operator invites the same email, the account joins the school without losing documents. The Game kelas trial keeps its own 7 days (D-159).
- **Public wording (D-459):** "tanpa menulis prompt" stays on `/`; Google Gemini is named; BOS is not mentioned on public pages or in the terms; no region is named as the pilot.
- **Add-ons:** the D-158 list is only the starting configuration; the console decides (D-211). Pages tag add-on features "Fitur tambahan"; the built pages read the tags from the console mapping.
- **Terms and banned words** follow `docs/final/design-system.md`. Checked: no "siswa", "P5", "taraf serap", "absensi", "teguran", "tanda tangan elektronik", "tunggakan", "kurang bayar", "belum lunas", "cerdas", "canggih" in the Indonesian copy.
- **Legal drafts:** each carries "Versi", "Berlaku sejak: [tanggal]" and the visible note "DRAF — belum ditinjau ahli hukum". Unknown facts are placeholders; no company details were invented. Security statements describe the controls decided in D-398, D-400, D-404, D-405, D-426, D-430 and the Fondasi baseline; most are not built yet.
