# SIGRAK

Web app for SD/MI teachers and school leaders. Product and process docs live in [`docs/`](docs/); agents start at [`CLAUDE.md`](CLAUDE.md).

Stack (phase R, D-388…D-405): AdonisJS 7 on Node 26 (TypeScript strict), Inertia + React 19 with the React Compiler, Vite, Tailwind 4 + shadcn/ui, Lucid on PostgreSQL 18, Redis, Japa.

## Three hosts

| Host | Who | Guard | Session cookie |
|---|---|---|---|
| `app.<domain>` | school users | `web` (`users`) | `sigrak_app_session` |
| `admin.<domain>` | Tim SIGRAK staff | `staff` (`staff_users`) | `sigrak_admin_session` (SameSite=Strict, 60 min) |
| `ujian.<domain>` | exam participants | `exam` (`exam_participants`) | `sigrak_exam_session` |

Each host has its own `/masuk` login page and its own routes. `GET /healthz` answers on every host.

## Local setup

Requirements: Node 26 (`.nvmrc`), pnpm 12 (`npm i -g pnpm@12.23.0`; the version is pinned in `package.json`, D-422), Docker (or a local PostgreSQL ≥ 16 and Redis).

1. Map the local hostnames to your machine, once:

   ```sh
   echo "127.0.0.1 app.sigrak.test admin.sigrak.test ujian.sigrak.test" | sudo tee -a /etc/hosts
   ```

   On Windows add the same line to `C:\Windows\System32\drivers\etc\hosts`.

2. Start PostgreSQL 19 and Redis, and configure the app:

   ```sh
   docker compose up -d
   cp .env.example .env
   pnpm install --frozen-lockfile
   node ace generate:key
   ```

   `compose.yaml` creates the `sigrak` and `sigrak_test` databases. Without Docker, create both databases for a `sigrak` role yourself and adjust `DB_*` in `.env`.

3. Create the tables and the demo data:

   ```sh
   pnpm db:migrate
   pnpm db:seed
   ```

4. Run the dev server and open <http://app.sigrak.test:3333/masuk>:

   ```sh
   pnpm dev
   ```

5. For AI jobs (Coba AI at `/coba-ai`), run the `worker-ai` process role in a second terminal. With `AI_PROVIDER=fake` (the default) it needs no Gemini key:

   ```sh
   node ace queue:work ai
   ```

## Commands

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server with HMR |
| `node ace queue:work ai` | Worker of the `ai` queue (process role `worker-ai`, D-388); `exports` and `default` likewise |
| `pnpm test` | Japa tests (uses `.env.test`: database `sigrak_test`, memory sessions and limiter) |
| `pnpm lint` / `pnpm format:check` | ESLint / Prettier |
| `pnpm typecheck` | TypeScript, server and frontend |
| `pnpm build` | Production build into `build/` |
| `pnpm db:migrate` | Run migrations (forward-only, D-085) |
| `pnpm db:seed` | National holidays (from `docs/data/calendar`) and demo data |
| `pnpm db:fresh` | Drop everything, migrate, seed (development only) |
| `pnpm audit:prod` | `pnpm audit` of production dependencies (high and critical) |

CI (`.github/workflows/ci.yml`) runs lint, format check, typecheck, audit, tests against PostgreSQL 19 and Redis, and the build.

## Layout

- `app/` controllers per area (`school/`, `staff/`, `exam/`), models, middleware, services, validators; `app/services/ai` (gateway, key selection, Gemini and fake providers), `app/services/generation` (step runner, Transmit progress, cancel), `app/services/queue` (BullMQ queues and workers), `app/jobs` (one plan per content type)
- `commands/queue_work.ts` the worker process roles
- `config/hosts.ts` hostnames and areas; `config/session.ts` per-area session settings
- `database/migrations`, `database/seeders`; `database/schema.ts` is generated by `migration:run`
- `inertia/` React pages, layouts and components (`components/ui` from shadcn/ui; `components/icon.tsx` is the single icon wrapper, placeholder until the licensed Hugeicons Pro files arrive, D-402)
- `resources/lang/id/*.json` Indonesian UI copy with English keys
- `tests/functional`, `tests/unit` Japa tests
- `scripts/ai-job-spike/measure.cjs` R0-06 browser measurement of progress latency and worker restarts
